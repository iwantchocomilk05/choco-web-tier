# 웹툰 티어표 웹사이트

## 실행 방법
```bash
cd /workspace/choco-web-tier
npm install
ADMIN_USERNAME='myid' ADMIN_PASSWORD='mypassword' npm start
```
브라우저: `http://localhost:3000`

## 주요 변경사항 (요약 카드 + 상세 모달)
- 티어 목록 카드: 표지, 제목, 점수(예: `8.5 / 10`)만 표시
- 상세 정보(상세 평가 이유/댓글): 카드 클릭 시 모달에서만 표시 및 입력
- 점수 체계: 10점 만점(0~10, 소수점 1자리)

## 관리자/공개 권한
- 관리자 로그인 후에만 웹툰 추가/수정/삭제 가능
- 일반 방문자는 조회 + 댓글 작성 가능

## 입력 필드
- 제목, 장르, 티어, 점수(0~10), 표지 이미지 URL, 한 줄 추천 이유, 상세 평가 이유

## 데이터 호환
- 기존 `rating`(5점) 데이터가 있으면 서버에서 `score`(10점)로 fallback 변환해서 읽습니다.
